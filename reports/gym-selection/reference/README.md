# Crimson 840 reference set

All three saved angles show the same compact 840-seat basketball arena study and were inspected before procedural modeling.

The procedural study reproduces the reference's pale maple, crimson paint and perimeter, dark seating, white balcony fascia, metal rails, upper-level arched windows, compact bowl, and end-wall scoreboard. It does not claim exact architectural drawings, structural engineering, sponsor marks, or a photogrammetric reconstruction.
