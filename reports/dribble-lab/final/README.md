# NOVA COURT Dribble Lab — Final QA

Deterministic visual review of the production-shared crossover and spin
choreography. All captures are 1280 × 720 PNGs from the local production
server with ball-path and scale guides enabled.

## Reproduction

Start the game server:

```powershell
npm run serve
```

Open these exact URLs:

- Crossover start:
  `http://127.0.0.1:4174/dribble-lab.html?move=crossover&progress=0&trace=1&guides=1`
- Crossover handoff:
  `http://127.0.0.1:4174/dribble-lab.html?move=crossover&progress=0.5&trace=1&guides=1`
- Crossover finish:
  `http://127.0.0.1:4174/dribble-lab.html?move=crossover&progress=1&trace=1&guides=1`
- Spin start:
  `http://127.0.0.1:4174/dribble-lab.html?move=spin&progress=0&trace=1&guides=1`
- Spin handoff:
  `http://127.0.0.1:4174/dribble-lab.html?move=spin&progress=0.56&trace=1&guides=1`
- Spin finish:
  `http://127.0.0.1:4174/dribble-lab.html?move=spin&progress=1&trace=1&guides=1`

The deterministic browser-console hook exposes the same states:


## Review notes and limitations

- The lab uses the production `ProceduralPlayer`, NOVA Flight shoes, shorts
  simulation, and basketball factory. Production gameplay calls the same
  `sampleFeaturedDribbleMove` ball-path math for crossover and spin.
- Gameplay still owns velocity and collision response; the lab displays the
  authored local root displacement rather than simulating defender contact.
- Arms use deterministic joint targets rather than a full inverse-kinematics
  hand solver. The handoff weights and ball endpoints match, but fingers do
  not wrap dynamically around the ball.
- The spin is a complete 360° review pose. During the middle frame, the body
  intentionally occludes part of the protected rear-hip ball arc.
